# Rubien 0.8.2 release preparation

Target: Rubien 0.8.2, build 53.

## Scope and release notes

- Fix an app update check that could be missed when Rubien starts while its updater is busy.
- Keep Software Update readiness and the last-checked time current in Settings.

The launch request waits for Sparkle to become idle, without polling or duplicate
checks. Manual checks and automatic-check opt-out cancel the pending request.
This corrects launch-check logic first shipped in 0.1.11; the relevant controller
was unchanged between 0.7.9 and 0.8.0.

## Validation and release steps

1. Independent review and simplify reuse, quality, and efficiency passes found no
   actionable issues. The final build and all 17 updater tests passed.
2. Regenerate the CLI version for 0.8.2/build 53, commit preparation, push main,
   and require green CI for the exact preparation revision.
3. Validate CloudKit Development and Production, then build the unsigned app and
   matching browser-extension packages for the user-run candidate checks.
4. Present the exact version, notes, gate results, and release command for approval.
5. After approval, sign and publish through the release runbook, verify public
   Mac/Linux downloads and the appcast, and retain private debugging symbols.

No MCP package change or dependency upgrade is included. The existing dev-launch
comment edit is unrelated and must remain outside the release commits.
