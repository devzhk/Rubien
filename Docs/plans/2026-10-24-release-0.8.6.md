# Rubien 0.8.6 release preparation

Target: Rubien 0.8.6, build 57.

## Scope and release notes

- Restore native Codex updates with the latest official installer while preserving running sessions.

No dependency, database, browser integration, or npm package changes are planned.
Existing edits to the release runbook and dev-launch comments predate this work;
the user approved committing them separately (e5bc6d95).

## Implementation and validation

1. Inspect the current official bootstrap against the previously reviewed script.
   Record its SHA-256 and validate its retention, selection-history, and latest-channel behavior.
2. Add an opt-in production native-update test using a disposable home: install
   0.162 and 0.163, keep both app-server generations running, update to the public
   latest release through ProviderUpdateActionModel, verify old resources and late
   helper launches, then verify unused-release cleanup on a no-op update.
3. Advance the reviewed installer hash only after the retention test passes.
   Add a regression that rejects unknown script bytes before running a shell.
4. Build and run focused provider tests. Request the optional independent review
   and simplify sweep when the implementation is ready to commit.
5. Bump VERSION/BUILD.txt, regenerate the CLI version, commit and push preparation,
   and require green CI for the release-preparation revision.
6. Validate both live CloudKit environments, build the unsigned release candidate,
   and verify matching browser ZIPs. Skip the browser smoke check if comparison
   with v0.8.5 confirms there are no browser integration changes.
7. Present the exact notes, version/build, CI and CloudKit results, and release
   command for explicit approval under Docs/Release-Runbook.md before signing or
   publication.
