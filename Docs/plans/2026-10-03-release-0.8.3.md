# Rubien 0.8.3 release preparation

Target: 0.8.3, build 54.

## Release notes

- Add an Attachment sync (experimental) control in Settings → iCloud Sync for supplementary PDFs, Markdown files, and their annotations.
- Save the choice on each Mac and show when a restart is needed. Enable it on both Macs, then restart Rubien to begin testing sync.

## Gates

- Focused coordinator tests and live toggle/reminder verification passed before release preparation.
- User approved independent review and simplify reuse/quality/efficiency sweeps. All four found no actionable issues; all 37 coordinator tests passed again afterward.
- Commit, push, and require exact-revision CI; validate both CloudKit environments.
- Build and verify the versioned candidate. The user's waiver of unrelated browser smoke checks continues to apply to this app-only follow-up.
- Obtain approval of the exact signed release command after the gates pass.
- Verify public Mac/Linux artifacts and appcast, and retain private debugging symbols.

The existing attachment sync engine remains experimental and opt-in; two-Mac transfer validation is still pending. This release makes that opt-in accessible to users. No schema, dependency, MCP package, or browser behavior change is included.
