# Rubien 0.8.5 release preparation

Target: Rubien 0.8.5, build 56.

## Scope and release notes

- Mention library papers with @ directly after text, without inserting a space.
- Open PDF annotation notes in a consistent, clean editor.
- Spot notes with sharp, clickable badges that stay aligned while scrolling and zooming, with clear hover feedback.

## Validation and release steps

1. Independent review identified a rapid-scroll badge-positioning issue. The
   fix uses a separate frame coalescer and has a continuous-scroll regression
   test; the reviewer confirmed the finding is addressed. All 39 focused tests
   passed, and the isolated preview was verified with the selected build SDK.
2. Regenerate the CLI version for 0.8.5/build 56, commit preparation, push main,
   and require green CI for the exact preparation revision.
3. Validate CloudKit Development and Production, then build the unsigned app and
   matching browser-extension packages for the user-run candidate checks.
4. Present the exact version, notes, gate results, and release command for approval.
5. After approval, sign and publish through the release runbook, verify public
   Mac/Linux downloads and the appcast, and retain private debugging symbols.

No MCP package change or dependency upgrade is included. The existing dev-launch
comment edit is unrelated and must remain outside the release commits.
