# Rubien 0.8.1 release preparation

Target: Rubien 0.8.1, build 52.

## Scope

Show advisory update notices for native Claude Code and Codex installations when
a fresh version check finds a newer public release. Preserve Later, automatic-check
preferences, freshness checks, and the separate validation of update actions.
Cover both newly fetched results and cached results from an earlier app session.

## Release notes

- Fix missing update notices for native Claude Code and Codex installations when a newer release is available.

## Steps

1. Validate the notice fix and regenerate the CLI version for 0.8.1/build 52.
2. Confirm the independent review and simplify choices required by AGENTS.md.
3. Commit the scoped fix and release preparation, then push and require green CI
   for the exact preparation revision.
4. Validate CloudKit Development and Production, then build an unsigned release
   candidate and matching extension packages for the user-run smoke checks.
5. Present the exact release command, version, notes, and gate results for approval.
6. After approval, sign and publish through the release runbook, verify Mac/Linux
   downloads and the appcast, and retain private symbols.
